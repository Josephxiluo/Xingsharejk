# 药品保险报销活动福利平台 · 运营后台 DEMO

这是一个基于 Fily Admin 风格搭建的 **PC 运营后台静态页面 DEMO**，用于在正式系统开发前与客户确认后台页面结构、业务流程和功能范围。

## 当前完成范围

> 已按需求文档中的“运营后台（PC 网页后台）”范围完成静态演示页面搭建。

| 后台模块 | DEMO 覆盖内容 | 页面锚点 |
| --- | --- | --- |
| 运营总览 | 活动、报名、理赔、打款指标概览 | `#dashboard` |
| 活动管理 | 活动新增/编辑入口、状态、活动时间、图文内容、二维码生成、入组/理赔表单字段配置、入组/理赔多份协议自定义 | `#activities` |
| 活动报名申请管理 | 筛选、申请列表、资料摘要、协议确认、审核通过、审核拒绝、数据导出 | `#enrollments` |
| 理赔申请管理 | 状态看板、理赔列表、资料查看、受理、驳回、状态更新、待打款导出 | `#claims` |
| 打款状态管理 | 待打款导出、保险公司线下处理、打款结果批量导入流程 | `#payments` |
| 会员管理 | 会员列表、注册时间、活动参与记录、理赔订单记录、资料上传记录 | `#members` |
| 合作药房管理 | 药房名称、地址、电话、活动关联、坐标/导航信息展示 | `#pharmacies` |
| 一键热线管理 | 客服电话、企业微信客服说明、二维码展示位 | `#hotline` |
| 运营账号与权限管理 | 后台账号与角色权限示意 | `#permissions` |

## 如何本地预览

### 方式一：直接打开 HTML

在文件管理器或浏览器中打开项目根目录下的 `index.html` 即可预览。

### 方式二：启动本地静态服务（推荐）

在项目根目录执行：

```bash
python3 -m http.server 4173
```

然后在浏览器访问：

```text
http://127.0.0.1:4173/index.html
```

如果端口 `4173` 被占用，可以换成其他端口，例如：

```bash
python3 -m http.server 8080
```

并访问：

```text
http://127.0.0.1:8080/index.html
```

## 交付说明

- 当前 DEMO 是纯前端静态页面，按钮、表格、上传区、表单字段配置、协议配置、导出入口均为演示占位。
- 当前不包含接口、数据库、真实登录权限、真实文件上传、真实 Excel 导入导出、自动打款或第三方系统对接。
- 后续正式开发时，可以在此页面结构基础上接入真实接口、权限控制、数据表格、文件上传和导入导出逻辑。
